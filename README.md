# Media Studio

استوديو محتوى يشتغل من الآيباد: تصميم، موشن جرافيك، فيديو، وأفاتار بشري، عبر Claude Code.

## طريقة الاستخدام

1. افتح تطبيق Claude ← تبويب **Code** (أو claude.ai/code).
2. ابدأ جلسة جديدة واختر المستودع **media-studio**.
3. اكتب طلبك بالعربي، مثل:
   - «سو لي فيديو ريلز 15 ثانية لشعار Myticket يتحرك»
   - «صمم بانر لفعالية بخط Vazir بمقاس إنستغرام»
   - «سو فيديو شرح دقيقة عن كيف تحجز تذكرة في Myticket»
4. الفيديو النهائي يوصلك رابطه في المحادثة، ويكون محفوظًا في مجلد `deliverables/`.

## الموجود

| المجال | المهارات |
|---|---|
| التصميم | UI/UX Pro Max (ألوان، خطوط، هوية، بانرات، سلايدات) |
| الموشن والفيديو | HyperFrames (الأساسي)، Remotion (بشرط الترخيص)، OpenMontage (يُنزّل عند الحاجة) |
| الأفاتار البشري | HeyGen (يحتاج مفتاح API مدفوع) |

التفاصيل والقيود في `CLAUDE.md`، والتراخيص في `third_party/`.

## مطلوب منك مرة وحدة

- ارفع شعار Myticket بخلفية شفافة (PNG أو SVG) إلى `brand/logo/`.
- لاستخدام HeyGen: أضف مفتاح الـ API كـ Network Secret في إعدادات بيئة السحابة، للنطاق `api.heygen.com`.
